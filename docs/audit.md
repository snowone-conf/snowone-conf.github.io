# Аудит снапшота snowone.ru

Снят 2026-09-25 скриптом `tools/mirror.py`. Список страниц, редиректов и ошибок лежит в `docs/snapshot-manifest.json`.

## Что за сайт
- Next.js (pages router, SSG) — общий фронтенд конференций JUG Ru Group. Все страницы сезона рендерятся одним шаблоном `/conference/[status]/[version]`, данные идут из их CMS (Squidex) и SRM.
- Один buildId: `g1sViIGZN-_nzCP60h37e`, одна локаль (`ru`). Английской версии на сайте нет (`/en/` отдаёт 404).
- Картинки и логотипы лежат на CDN `squidex.jugru.team`.
- Архив прошлых лет на текущем сайте — только `/archive/2025/`. Страниц 2020–2024 (`/2020/ru` и т.п.) уже нет, они отдают 404. Если они нужны, остаётся web.archive.org.

## Что сделано в снапшоте
| Что | Решение |
|---|---|
| HTML-страницы (главная, спикеры, доклады, персоны, партнёры, расписание, архив 2025, юр. документы) | сохранены 1:1 по тем же URL (`<path>/index.html`) |
| Ассеты Next.js (JS/CSS, в том числе чанки, которые подгружаются лениво) | скачаны целиком: работают гидратация и меню |
| JSON-данные страниц `/_next/data/…` | скачаны (оба варианта: с `ru/` и без), клиентская навигация работает |
| Картинки squidex (135 шт.) | скачаны в `snapshot/squidex/`, ссылки переписаны. Фото больше 300 КБ уменьшены до 800 px (−93 МБ, внешне без изменений) |
| PDF со слайдами (14 шт., ~200 МБ, самый большой — 95 МБ) | **не скачаны**, ссылки по-прежнему ведут на squidex.jugru.team — см. «Риски» |
| Редиректы (`/partners/x` → `/partners/x/`, `/talks/` → `/schedule/`, `/schedule/` → `/schedule/days/` и т.п.) | HTML-заглушки с meta refresh и canonical |
| 404 | `404.html` взят с оригинала |
| JS-хелпер картинок `new URL(src)` падал на локальных путях | патч в `tools/mirror.py` (`JS_PATCHES`): добавлен базовый URL |

Проверено в headless Chromium на главной, спикерах, расписании, докладе, персоне, партнёрах, архиве, CoC и организаторах: ошибок JS нет, 404 на ресурсы нет, переходы по меню работают.

## Риски
- Всё, что осталось на `*.jugru.*` (слайды, CFP, трекинг), может пропасть в любой момент, когда JUG Ru закроет доступ.
- Снапшот — это минифицированный бандл Next.js, дорабатывать его неудобно. Он временный, до Hugo-версии.
- Next.js использует корневые пути (`/_next/…`, `/squidex/…`). Снапшот работает **только из корня домена**: на адресе вида `https://<owner>.github.io/<repo>/` он не заработает (см. README).
