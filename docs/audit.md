## Риски
- Снапшот — это минифицированный бандл Next.js, дорабатывать его неудобно. Он временный, до Hugo-версии.
- Next.js использует корневые пути (`/_next/…`, `/squidex/…`). Снапшот работает **только из корня домена**: на адресе вида `https://<owner>.github.io/<repo>/` он не заработает (см. README).

## Пересборка на Hugo: отличия от старого сайта
Hugo-версия повторяет разметку и стили платформы, данные перенесены скриптом `tools/import_nextdata.py`. Намеренные отличия:

| Что | Было | Стало |
|---|---|---|
| Подписка на новости | форма e-mail → `POST /api/subscribe/` (не работала без JUG Ru) | тот же баннер, кнопка ведёт в Telegram-канал (`params.subscription.url`) |
| Время докладов | в часовом поясе браузера, подписано «(UTC±0)» и т.п. | новосибирское время, подписано «(Новосибирск)» |
| Избранное, вкладка «Избранное», настройки расписания | работали через API JUG Ru | убраны |
| FAQ в подвале | ссылка на `/registration/faq/` (404) | не показывается, пока нет страницы `content/faq/` |
| Прошедшие выступления на странице докладчика | карточки с фильтром по годам | упрощённые карточки: формат, год, название, язык, ссылка в архив |
| Баннер cookies | показывался всегда | только если включена своя аналитика |
| `/schedule/`, `/talks/`, `/persons/` | редиректы сервера | HTML-редиректы |
| Архив `/archive/**` | страницы платформы | те же страницы, заморожены в `static/archive/` |
