    • информация о браузере;
    • технические характеристики Устройства и программного обеспечения;

В рамках предоставленного согласия я предоставляю Оператору право на совершение с моими персональными данными любых действий, включая, но не ограничиваясь: сбор, систематизацию, накопление, хранение, уточнение (обновление, изменение), использование, обезличивание, блокирование, уничтожение, передачу персональных данных партнерам Администрации, перечень которых доступен по ссылке, а также осуществление иных необходимых действий с персональными данными с учетом действующего законодательства.

    • улучшение качества обслуживания Оператора, организация улучшения программного обеспечения Сайта;
    • использование моих персональных данных для целей надлежащего функционирования Сайта в соответствии с моими ожиданиями, в частности — для моей корректной идентификации;

    • проведение статистических и иных исследований использования Сайта на основе обезличенных данных.

Настоящее согласие либо подписывается моей простой электронной подписью, применение которой установлено пользовательским соглашением об использовании Сайта, принятым в момент моей регистрации, либо выражается моими конклюдентными действиями, в том числе регистрацией на Сайте , заполнением форм, нажатием кнопки «Согласен», участием в мероприятиях Оператора и другими аналогичными действиями.
