<p>C 2011 года работал в компании Excelsior, где был одним из разработчиков Excelsior JET &mdash; сертифицированной реализации Java SE, основанной на оптимизирующей AOT-компиляции. Сейчас работаю над компиляторами, JVM и новыми языками программирования. В основном занимаюсь рантаймом: GC, загрузкой классов, поддержкой многопоточности, профилированием и так далее.</p>
<p>Сооснователь и один из лидеров JUGNsk &mdash; официальной Java User Group в Новосибирске. Один из основателей профиля &laquo;Системное программирование&raquo; на ММФ НГУ, где преподаю на многих курсах.</p>
