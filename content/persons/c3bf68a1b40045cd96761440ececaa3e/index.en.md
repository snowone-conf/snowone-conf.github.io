<p>Lead developer of the search platform at Ozon. I create new technical features in search, such as fast attribute storage, search query optimizer, and high-performance data formats. I improve the performance of the engine and related subsystems. I develop internal team tools, including a search index analyzer, an advanced query parser, and a cluster management client, and I also participate in the development of the Java platform.</p>
<p>Main development languages: Java, Rust.</p>
<p>I am an Open Source enthusiast and have contributed to OpenJDK, Rust, Lucene, one-nio, jrsonnet, and Log4j.</p>
<p>A proponent of strict typing and maximum static verifiability of code.</p>
<p>In my spare time, I work on binding projects for Flipper Zero and the implementation of a modular game server. I maintain the nixpkgs repository and wrote a quantum programming language.</p>
<p>Previously worked in game development, creating game servers and the infrastructure around them.</p>
<p>Information security specialist. I teach a course on algorithms at MSTU and on Java at ITMO. Speaker and expert at JPoint, Joker, and SnowOne conferences.</p>
