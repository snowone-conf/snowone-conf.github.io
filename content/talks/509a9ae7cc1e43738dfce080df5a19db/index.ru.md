<p>Познавательно-рассказывательный доклад, призванный показать Java-разработчикам Error Prone как инструмент для минимизации багов в их коде, простой в использовании и энфорсящий хорошие практики по умолчанию.</p>
<p>Я расскажу про статический анализ, покажу Error Prone как хороший инструмент для статического анализа, а также продемонстрирую, что Error Prone просто расширяем для своих задач.&nbsp;</p>
<p>Доклад будет интересен:</p>
<ul>
<li>опытным разработчикам, которым Error Prone может принести пользу как инструмент для анализа и улучшения уже существующих проектов;</li>
<li>продвинутым разработчикам, которые пишут внутренние библиотеки и хотят обеспечить их правильное использование (для этого можно просто написать свой плагин для Error Prone);</li>
<li>начинающим разработчикам, которым может быть полезно показать удобный инструмент, позволяющий писать более чистый, предсказуемый и поддерживаемый код.</li>
</ul>
